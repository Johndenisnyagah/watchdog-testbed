# Security policy

This repository is a deliberately vulnerable test target. The outdated packages pinned in `requirements.txt` are intentional, so reports about them are out of scope and will be closed.

To report a vulnerability in the sbom-watchdog action itself, or in this repository's workflow (for example a way to make it run untrusted code or leak its token), please use [private vulnerability reporting on sbom-watchdog](https://github.com/Johndenisnyagah/sbom-watchdog/security/advisories/new) rather than a public issue.
